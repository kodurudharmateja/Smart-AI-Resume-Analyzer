# Smart AI Resume Analyzer

## Overview

Smart AI Resume Analyzer is a web-based application that helps users evaluate and improve their resumes through AI-powered analysis, ATS scoring, keyword optimization, and personalized recommendations.

## Features

* Resume Parsing
* ATS Compatibility Analysis
* Keyword Gap Detection
* Skills Assessment
* Resume Scoring
* AI-Powered Recommendations
* Interactive Dashboard

## Technologies Used

* Python
* Streamlit
* SQLite
* spaCy
* NLTK
* Scikit-learn
* Google Gemini API

## Key Learnings

* Natural Language Processing
* Resume Parsing
* Information Extraction
* AI Integration
* Interactive Web Application Development
* Data Visualization
